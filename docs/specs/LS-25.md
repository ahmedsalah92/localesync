# Claude Code prompt — surface the un-measurable reason, exclude empty layers

Read `docs/agent-guidelines.md` and `docs/specs/LS-8.2.md` §2.6–§2.7 before starting.

Two related changes to the overflow panel. The engine already computes why a node could not be
measured (`OverflowVerdict.reason`); the UI discards it everywhere except `resolveState`'s
`fonts-unavailable` gate. Make the reason visible, and stop treating empty text layers as findings.

## 1. `src/main/overflow/index.ts` — exclude empty nodes from the scan

In `scanOverflow`, extend the eligibility filter:

```ts
const eligible = models.filter((model) => !model.hidden && !model.empty);
```

Update the surrounding comment on `scanOverflow` to state the rule and its reason: an empty text
layer cannot break a layout, which is the same argument that already excludes hidden nodes. LS-3
tags empty nodes and never drops them — filtering is this layer's job, not traversal's.

**Do not** remove the `model.empty` gate in `measure.ts` or the `'empty'` member of `OverflowReason`.
The gate is the guard for direct `measureOverflow` callers (`src/main/overflow/check.ts` pass 1 calls
it without going through `scanOverflow`), not the filter. Add a one-line comment at that gate saying
so, otherwise the next reader deletes it as dead code.

## 2. `src/ui/shell/primitives/Tooltip.tsx` — wrapping variant

The current tooltip is sized for the 16×16 jump icon: `whiteSpace: 'nowrap'`, anchored `right: 100%`.
A sentence needs to wrap. Add an opt-in prop (`wide?: boolean`, or `maxWidth?: number` if you prefer
the explicitness) that switches to `whiteSpace: 'normal'` with a `maxWidth` of about 220px and
left-aligned text. The anchor stays `right: 100%` — the verdict span sits at the right edge of the
row, so leftward is where the room is, and 220px clears the 400px iframe default. Default behaviour
for existing call sites must be byte-identical; the jump icon keeps `nowrap`.

## 3. `src/ui/shell/ResultsRow.tsx` — optional tooltip on the verdict span

`RowMeta` gains `tooltip?: string`. When present, wrap the verdict `<span>` in `Tooltip` with the
wrapping variant; when absent, render exactly as today.

Preserve the meta line's layout precisely — this is the regression LS-8.2 §2.6 exists to prevent.
`Tooltip`'s outer element is `display: inline-flex` with no style hook, so put the flex on a wrapper
rather than on the tooltip:

```tsx
<span style={{ flex: '0 0 auto', whiteSpace: 'nowrap' }}>
  {props.meta.tooltip === undefined ? props.meta.verdict : <Tooltip wide label={props.meta.tooltip}>{props.meta.verdict}</Tooltip>}
</span>
```

The label yields; the verdict never does. Keep the doc comment on `RowMeta` accurate.

## 4. `src/ui/overflow/copy.ts` — the words

Add one exhaustive map beside `VERDICT_WORD`:

```ts
export const REASON_COPY: Record<OverflowReason, { word: string; tooltip: string } | null> = { … };
```

`null` for the six measurable reasons (`exceeds-fixed-box`, `truncated-fixed-box`, `maxLines-cap`,
`maxHeight-cap`, `exceeds-container-height`, `parent-escape`, `no-container` — check the union in
`src/common/models.ts` and cover every member). Exhaustive rather than a five-entry partial map so a
new `OverflowReason` is a compile error here, matching the `severityRank` and `toneToken` discipline.

Entries for the five un-measurable reasons:

| `reason` | `word` | `tooltip` |
|---|---|---|
| `missing-font` | `font missing` | The font isn't installed, so Figma won't re-flow this text. Install it and scan again. |
| `mixed-font-missing` | `font missing` | One of several fonts on this layer isn't installed. |
| `no-bounds` | `no bounds` | This layer has no rendered box, so there is nothing to measure against. |
| `unsupported-language` | `not supported yet` | Overflow in this language depends on glyph width, which the engine does not model yet. |
| `empty` | `empty` | This layer has no text. |

`rowMeta` changes:

- When `verdict.verdict === 'unmeasurable'` and `verdict.reason` is present and its `REASON_COPY`
  entry is non-null → use that entry's `word` in the verdict chunk and set `tooltip`.
- Otherwise → today's behaviour exactly: `VERDICT_WORD[verdict.verdict]` and no tooltip.

The fallback is load-bearing. `reason` is optional on `OverflowVerdict` for all four verdict values;
nothing produces an un-measurable verdict without one today, but the type permits it and we are not
changing the type. A missing reason renders `un-measurable`, never blank and never a throw.

The `•` prefix, the `Math.ceil` amount rule, and the omit-when-absent rule are unchanged. Un-measurable
rows carry no `overflowPx`, so the amount never appears on them.

Add a comment recording that LS-14 owns the final wording and edits this file — same note the header
already carries.
